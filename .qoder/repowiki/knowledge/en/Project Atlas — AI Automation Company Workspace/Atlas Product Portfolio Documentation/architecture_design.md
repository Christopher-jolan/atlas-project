The module is a flat collection of product directories under `03_Products/`, one per product (`Atlas CRM`, `Atlas Flow`, `Atlas Voice`, `Atlas Agent/V1`, `Atlas Call Intelligence/V1`). Each product follows an identical documentation layout: `README.md` (overview/status), `Architecture.md`, `API.md`, `Database.md`, `Features.md`, `Roadmap.md`, `Todo.md`. The only fully fleshed-out product is `Atlas Call Intelligence/V1`, which includes a concrete Docker-based deployment via `docker compose`, n8n workflow imports, a PostgreSQL schema, environment variables, and a fixed JSON response schema (`schema.json`). Other products are in planning or early stages with mostly empty placeholder files. There is no shared code; the module serves as a product catalog and design spec repository.
