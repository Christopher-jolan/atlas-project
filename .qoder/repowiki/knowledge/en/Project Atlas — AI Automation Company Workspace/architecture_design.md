The root is a documentation-and-deployment workspace rather than executable code: it groups three sibling concerns side by side so they can be developed in parallel. The `company_strategy_market` folder holds bilingual (Persian/English) strategy and positioning docs; the `products` folder documents each Atlas product line (CRM, Flow, Voice, Agent, Call Intelligence) with architecture, API, database, features, roadmaps, and task plans; the `docker_infrastructure` folder provides the Compose-based runtime that deploys PostgreSQL, n8n workflows, a FastAPI admin panel, and an SMTP mailer to support the call intelligence product. Cross-child linkage is conceptual — product specs in `products` drive the services defined in `docker_infrastructure`, while both are guided by the strategic positioning in `company_strategy_market`. Root-level markdown files (`Automation Ideas.md`, `Business Ideas.md`, `Pain Points.md`) serve as living idea/backlog stores that feed into the product and strategy folders.
