The module defines a four-service stack via `docker-compose.yml`: (1) `postgres:16` with a healthcheck and two init SQL scripts (`001_call_intelligence.sql`, `002_panel_seed.sql`) under `postgres/init/` that seed the `atlas` database; (2) `n8n` (official image) configured to persist workflows and data in `./n8n/data/` and connect to the shared Postgres instance; (3) `panel`, a custom-built FastAPI app (built from `panel/Dockerfile`) exposing Jinja2-rendered HTML dashboards on port 8080, reading DB credentials and AI model settings from environment variables; (4) `mailer`, a Python 3.12 slim container running `mailer.py` as an HTTP server on port 8765 that forwards emails via Yahoo SMTP. Services depend on Postgres being healthy before starting, and all secrets are injected through `.env` (template in `.env.example`). The panel's internal architecture is layered: `main.py` declares routes and a cookie-based auth middleware, `queries.py` performs raw SQL via `db.py` (psycopg2 with `RealDictCursor`), `ai.py` calls the configured LLM endpoint, and templates live under `panel/templates/` with static assets under `panel/static/`. n8n workflow definitions are stored as JSON files in `n8n/workflows/` and can be loaded into the n8n instance.
