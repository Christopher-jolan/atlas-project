Copy `.env.example` to `.env` and fill in `AI_API_URL`, `TRANSCRIPTION_API_URL`, `AI_API_KEY`, `ATLAS_MANAGER_EMAIL`, and optionally `PANEL_PASSWORD`. Start the full stack with `docker compose up -d`; the panel is reachable at `http://localhost:8080`, n8n at `:5678`, and the mailer HTTP API at `POST http://localhost:8765/send` with `{to, subject, body}` JSON. Database schema and seed data are applied automatically on first run via `postgres/init/*.sql`.
